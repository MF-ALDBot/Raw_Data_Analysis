# Raw_Data_Analysis

Data analysis code and experimental datasets accompanying:

> **An automated materials acceleration platform for active-learning-driven atomic layer deposition**  
> M.B. Alghalayini\*, T. Kodalle\*, A. Gashi, A. Razumtcev, M. Surendran, S. Aloni, A.M. Schwartzberg, E.S. Barnard  
> *Digital Discovery*, 2026 (DOI: TBD)

This repository contains the Gaussian process (GP) modeling pipeline used to process PE-ALD experimental campaign data. It loads raw ellipsometry-derived growth rate measurements from [ALDBot](https://https://github.com/MF-ALDBot/) experiments, fits GP models, computes predictive accuracy (RMSE) and information gain metrics, and generates the synthesis-property relationship analysis (including SHAP feature importance) reported in the paper.

## Experimental campaigns

Seven PE-ALD TiO₂ campaigns (TDMAT precursor, 75°C substrate) are included. The two campaigns central to the paper are:

| Campaign | Dimensionality | Experiments | Role in paper |
|---|---|---|---|
| `250730_TDMAT_Campaign0009` | 4D subspace | 100 (5 random + 95 GP) | Fig. 2 — active learning vs. random sampling benchmark |
| `250812_TDMAT_Campaign0012` | 12D full space | ~200 | Fig. 3 — SHAP analysis and validation sweeps |

Additional campaigns are included for supplementary analysis, cross-validation, and repeat experiments.

## Usage

Open `analyze_full_campaign.ipynb` in Jupyter and run the cells sequentially. The notebook:

1. Reads a campaign configuration YAML from `campaigns/`
2. Loads and merges the corresponding raw JSON files from `Data/`
3. Fits `GPModelConstMean` to the accumulated experimental data
4. Computes RMSE on 100 randomly drawn held-out test sets (50 experiments each)
5. Computes per-step information gain (KL divergence)
6. Generates GP posterior predictions, uncertainty maps, and SHAP analysis
7. Writes processed results back to the campaign's subdirectory under `campaigns/`

To analyze a specific campaign, set the campaign YAML path at the top of the notebook and re-run.

## Data format

### Campaign configuration YAML (`campaigns/<name>.yaml`)

Each campaign is described by a short YAML file:

```yaml
short_name: 250730_TDMAT_campaign0009
date: 2025-07-30
description: "TiO2 campaign 0009 TDMAT 75C, exploring 4 timing params"
campaign_run_jsons:
  - "Data/250730_TDMAT_Campaign0009/<id1>_aldbot_campaign_output.json"  # random init runs
  - "Data/250730_TDMAT_Campaign0009/<id2>_aldbot_campaign_output.json"  # GP-guided runs
```

Multiple JSON files per campaign reflect sequential run batches (e.g., initialization runs followed by GP-guided runs). The processed campaign overview (with full per-run metadata) is written to `campaigns/<name>/<name>_campaign_overview.yaml` by the notebook.

### Raw data (`Data/<campaign>/*_aldbot_campaign_output.json`)

Each JSON file contains a list of individual ALD experiment records. Key fields per experiment:

| Field | Description |
|---|---|
| `run_id` | Unique experiment identifier |
| `precursor_dose_time` | TDMAT dose duration (ms) |
| `plasma_prep_time` | O₂ plasma preparation time (ms) |
| `plasma_duration` | Plasma exposure time (ms) |
| `plasma_purge_time` | Post-plasma purge time (ms) |
| `ALD_purge_time` | Post-precursor purge time (ms) |
| `process_pressure` | Chamber pressure during precursor half-cycle (mTorr) |
| `plasma_pressure` | Chamber pressure during plasma half-cycle (mTorr) |
| `RF_power_setpoint` | RF source power (W) |
| `Ar_process_flow_rate` | Ar flow through plasma source (sccm) |
| `ALD_purge_flow_rate` | Ar flow through precursor line (sccm) |
| `precursor_purge_time` | Precursor line purge duration (ms) |
| `dep_rate_mean` | Growth rate — mean over cycles 10–25 (Å/cycle) |
| `dep_rate_deviation` | Growth rate standard deviation (Å/cycle) |
| `dep_rate_fit` | Growth rate from linear thickness fit (Å/cycle) |
| `Initial_thickness` | Cumulative film thickness at experiment start (Å) |
| `Number_of_ALD_cycles` | ALD cycles per experiment (fixed at 25) |
| `campaign_id` | ID of the ALDBot campaign batch this run belongs to |

The first 9 of 25 cycles are discarded to remove inter-experiment effects; growth rate is averaged over the remaining 16 cycles.

## GP model variants

Three model classes inherit from `GPModelBase` (`models/gpmodel_base.py`):

- **`GPModelConstMean`** (`gpmodel_constant_PriorMean.py`) — Uses a constant prior mean $\mu(\mathbf{x}) = c_1$ with $c_1$ estimated from data. This is the model used throughout the paper for the uninformed exploration strategy.

- **`GPModelALDWindow`** (`gpmodel_ald_PriorMean.py`) — Uses a piecewise ellipsoid prior mean that encodes prior knowledge of the ALD process window shape. Intended for cases where domain knowledge about the expected growth rate plateau is available. Not used in the abovementioned publication, but included as an alternative option to the constant mean. 

Both use an ARD Matérn-3/2 kernel with per-dimension length scales, fit by maximizing the log marginal likelihood via `gpCAM`.
